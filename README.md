# 課題確認 / Assignment Checker

大学の授業と課題の提出状態を管理するシンプルなPWAです。

- 授業名・曜日・時限・課題回数を登録
- 課題の「未」「済」（必要に応じて「完」）を切り替え
- 端末のローカルストレージに状態を保存
- Service Workerでオフライン閲覧に対応

HTML / CSS / JavaScript製。既存のホーム画面用アイコンはアプリ専用デザインのまま維持しています。
